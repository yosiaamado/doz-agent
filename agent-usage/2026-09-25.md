- Cache read mendominasi token (125.97M): konteks engineer yang besar dibaca ulang di setiap turn.
- Bug yang lolos self-review dan baru tertangkap reviewer/QA/security: warna hover kalah dari inline style, update state map menimpa key lain, lookup by id dari list yang terpaging, AC "A atau B" hanya diuji salah satu kondisi, endpoint agregat membocorkan data tanpa permission resource asal.
