## Notes

- The engineers were handed 4 slices (~20 files) in a single call and never reported `too-big`. That's the main reason runs hit `maxTurns` and why the continuation cost was so high.
- Cache reads dominate the token count (125.97M): the engineers' large context is re-read on every turn.
- Bugs that slipped past self-review and were only caught by the reviewer/QA/security: a hover colour losing to an inline style, a map state update overwriting other keys, a lookup by id from a paginated list, an "A or B" AC with only one condition tested, and an aggregate endpoint leaking data without the underlying resource's permission.
- Models are written per family (matching `model:` in the agent frontmatter). The exact model version per run is stored in `~/.claude/doz-agent/token-audit.csv` on the machine that ran the audit.
